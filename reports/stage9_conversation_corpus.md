### Content Type

Multi-turn conversational dialogues between users ("prompter") and assistants.
Each message includes:
- `message_id`: Unique identifier
- `parent_id`: References parent message (forms conversation trees)
- `user_id`: User identifier
- `created_date`: Timestamp
- `text`: The message content
- `role`: "prompter" or "assistant"
- `lang`: Language code (24 languages including English)
- `review_count`, `review_result`: Review metadata
- `deleted`: Boolean flag for deleted messages
- `rank`: Ranking score for response quality
- `synthetic`: Boolean flag for synthetic messages
- `model_name`: Model that generated the response (if assistant)
- `message_tree_id`: Groups messages into conversation trees
- `tree_state`: Conversation state
- Quality ratings: toxicity, severe_toxicity, obscene, identity_attack, insult, threat, sexual_explicit (float scores 0-1)
- Labels: Categorical quality labels (spam, fails_task, lang_mismatch, pii, not_appropriate, hate_speech, sexual_content, quality, toxicity, humor, creativity, violence)

### Suitability for Conversational Fine-Tuning

**High.** OpenAssistant/oasst1 is:
- Specifically designed for conversational AI training
- Contains multi-turn conversation trees (message_tree_id links related messages)
- Role metadata distinguishes user vs. assistant messages
- Language filtering available (English subset)
- Quality filtering available (toxicity scores, rank values, deleted flag)
- Apache-2.0 license (permissive)
- Real human-generated conversations (not synthetic)

### Files

Stored as Parquet. Reading requires `pyarrow` or `pandas` library.

## 4. Recommendation

**OpenAssistant/oasst1** is the recommended Corpus D source:
- Specifically designed for conversational AI training
- Multi-turn conversation trees with role metadata
- Language and quality filtering available
- Apache-2.0 license (permissive)
- Real human conversations (not synthetic)

**To use OpenAssistant/oasst1:**
1. Manually download the Parquet files from Hugging Face
2. Install `pyarrow` or `pandas` to read them
3. Filter for English messages (lang == "en")
4. Filter out deleted messages (deleted == False)
5. Filter for high-quality messages (review_result == True, low toxicity)
6. Group messages by message_tree_id to form conversations
7. Extract prompter/assistant pairs for conversational fine-tuning
8. Save as JSONL in the format: {"messages": [{"role": "user", ...}, {"role": "assistant", ...}]}
