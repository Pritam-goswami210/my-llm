### Suitability for Small CPU-Trained Model

**High.** WikiText-2 is:
- Small enough (4.72 MB downloaded) for CPU training

- Diverse vocabulary and topics
- Provides official train/validation/test splits (no leakage risk)

### Format

Each subset is available in two variants:
- **Raw**: Raw text before unknown-token replacement, suitable for character-level models
- **Non-raw**: Tokens with out-of-vocabulary words replaced by `<unk>`, suitable for word-level models

Files are stored as Parquet. Reading requires `pyarrow` or `fastparquet` library (not currently installed in this project).

## 4. Recommendation

**WikiText-2 (wikitext-2-raw-v1)** is the recommended Corpus C source:
- Small enough for CPU training
- Well-formed, diverse English prose
- Official train/validation/test splits prevent leakage
- CC BY-SA 4.0 license with clear attribution requirements
- Over 2x larger than Penn Treebank, retains original case/punctuation/numbers

**To use WikiText-2:**
1. Manually download the three Parquet files from Hugging Face
2. Install `pyarrow` to read them (`pip install pyarrow`)
3. Extract the `text` field from each split
4. Save as plain text files under `data/stage9/corpus_c/`
5. Update `data/manifests/corpus_manifest.json` to point to the files

If WikiText-2 cannot be obtained, use a Project Gutenberg public domain
novel (e.g., Sherlock Holmes stories) as an alternative.
